# LumaUI (Ver. 1.5.1)

[![Version](https://img.shields.io/badge/version-1.5.1-blue.svg)](https://github.com/oSsmXun256/lumaui/releases)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

---

LumaUIは、シンプルさと実用性を重視したCSS + JSベースのUIシステムです。

**Design Philosophy**: 情報量が多くても読みやすいことを最優先にし、装飾は控えめにします。面の階層はSurface(背景色の段階)とBorder(ボーダー)とElevation(影の段階)の3つの軸で表現し、Neumorphismは入力系・補助表現のアクセントとしてだけ使います。Glowやガラスなどの演出は持ちません。

- 見やすさ重視の設計
- 軽量で扱いやすい構成
- ライト / ダーク両対応
- Neumorphismを補助的に取り入れたデザイン
- surface/elevationトークン、縦タブ、静的カード/操作カードの明示を標準提供
- セマンティックカラー(success / error / warning / info)を標準提供

フレームワークに依存せず、直感的に使えることを目的としています。

## 検証

Node.js がある環境では次のコマンドで、結合版 `lumaui.css` が分割モジュールと同期していること、必須トークン/クラスが存在すること、`lumaui.js` の主要な挙動(モーダルのフォーカス復帰・スクロールロック、ドロップダウンのタブストップ除去、トーストのエスケープ処理、タブのキーボード操作)を確認できます。

```bash
npm test    # 検証のみ
npm run build  # lumaui.css を分割モジュールから再生成
```
